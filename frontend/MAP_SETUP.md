# 高德地图配置说明

## 1. 申请高德地图API密钥

1. 访问 [高德开放平台](https://lbs.amap.com/dev/key/app)
2. 注册并登录账号
3. 创建新应用
4. 获取API密钥（Key）

## 2. 配置API密钥

### 方法一：使用环境变量（推荐）

在项目根目录创建 `.env` 文件：

```bash
# 高德地图API密钥
REACT_APP_AMAP_KEY=your_actual_amap_key_here
```

### 方法二：直接修改配置文件

编辑 `src/config/mapConfig.ts` 文件：

```typescript
export const MAP_CONFIG = {
    AMAP_KEY: 'your_actual_amap_key_here',
    // ... 其他配置
};
```

## 3. 功能特性

- ✅ 显示所有接力棒的拍摄位置
- ✅ 绘制接力路线
- ✅ 点击标记查看详细信息
- ✅ 支持单组路线和全部路线切换
- ✅ 响应式设计，支持移动端
- ✅ 地图控件（缩放、比例尺、鹰眼等）

## 4. 使用说明

1. 在导航栏点击"路线图"查看所有路线
2. 在接力详情页面查看当前组的路线
3. 点击地图上的标记查看详细信息
4. 使用地图控件进行缩放和导航

## 5. 注意事项

- API密钥有使用限制，请合理使用
- 建议在生产环境中使用环境变量配置
- 地图加载需要网络连接
- 首次使用可能需要等待地图资源加载

## 6. 故障排除

如果地图无法加载：

1. 检查API密钥是否正确配置
2. 确认网络连接正常
3. 查看浏览器控制台是否有错误信息
4. 确认高德地图服务是否可用
