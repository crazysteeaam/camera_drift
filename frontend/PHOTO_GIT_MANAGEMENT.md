# 照片文件 Git 管理说明

## 概述

`public/photos/` 文件夹已被添加到 `.gitignore` 中，不会被上传到 Git 仓库。这是为了避免仓库过大和频繁的图片文件变更。

## 当前状态

- ✅ `public/photos/` 文件夹已被 Git 忽略
- ✅ 所有图片文件（.jpg, .jpeg, .png, .gif, .bmp, .tiff, .webp）都被忽略
- ✅ 之前跟踪的图片文件已从 Git 索引中移除

## 照片文件管理

### 1. 本地开发
- 照片文件仍然存在于本地 `public/photos/` 目录中
- 可以正常添加、修改、删除照片文件
- 本地开发环境不受影响

### 2. 团队协作
- 新团队成员需要手动添加照片文件到本地
- 可以使用以下方式分享照片文件：
  - 云存储服务（如 Google Drive, OneDrive, Dropbox）
  - 文件传输工具
  - 压缩包分享

### 3. 部署
- 部署时需要确保 `public/photos/` 目录存在
- 可以通过以下方式处理：
  - 在部署脚本中创建目录结构
  - 从云存储下载照片文件
  - 使用环境变量指定照片文件路径

## 自动化脚本

项目提供了以下脚本来管理照片：

```bash
# 创建目录结构
npm run update-photos

# 生成图片变体
npm run generate-phase2-variants

# 重新组织图片目录
npm run reorganize-phase2-images
```

## 注意事项

1. **不要** 将照片文件添加到 Git 仓库
2. **确保** 本地有完整的照片文件才能正常运行
3. **定期备份** 照片文件到云存储
4. **团队协作** 时及时分享照片文件更新

## 恢复照片文件

如果本地照片文件丢失，可以：

1. 从其他团队成员获取
2. 从云存储下载
3. 重新运行 `npm run update-photos` 创建目录结构
4. 重新添加照片文件到对应目录
