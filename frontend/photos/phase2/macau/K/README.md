# 澳门特别行政区 K组 图片目录

## 目录结构（推荐）
使用A1, A2这种目录结构，主图片和留言图片分别存放：
```
K/
├── K1/                    # 第一棒
│   ├── photos/                     # 主图片目录
│   │   ├── 任意名称.JPG           # 主图片
│   │   └── 另一张图片.JPG         # 主图片
│   └── message/                    # 留言图片目录
│       ├── 留言图片1.JPG
│       └── 留言图片2.JPG
├── K2/                    # 第二棒
│   ├── photos/                     # 主图片目录
│   │   └── 风景.JPG
│   └── message/                    # 留言图片目录
│       └── 留言图片.JPG
└── ...
```

## 传统目录结构（也支持）
如果不想使用A1, A2结构，也可以直接放在组目录下：
```
K/
├── 000001.JPG                     # 主图片
├── 000002.JPG                     # 主图片
└── message/                       # 留言图片
    ├── message_001.JPG
    └── message_002.JPG
```

## 自动更新
运行 `npm run update-photos` 会自动扫描此目录并更新配置文件。
