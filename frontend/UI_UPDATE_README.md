# 界面更新说明

## 更新内容

### 1. 标题优化
- **标题合并**：将"点亮中国"和"胶片漂流计划"合并为一行
- **去掉第二期**：移除了"第二期"副标题，使标题更简洁

### 2. 布局调整
- **地图位置**：将全国地图移到参与省份展示区域的上方
- **视觉层次**：优化了页面布局，地图作为整体概览放在前面

### 3. 筛选功能增强
- **省份筛选**：现在显示所有省份，不再只显示有小组的省份
- **筛选逻辑**：支持按省份名称进行精确筛选

### 4. 状态标识系统
- **视觉标识**：为每个小组添加了状态指示器
  - 🟠 进行中：橙色圆点
  - 🟢 已完成：绿色圆点
  - ⚪ 计划中：灰色圆点

- **进度信息**：
  - 进行中：显示进度百分比（如：50%）
  - 计划中：显示计划开启时间（如：2024-12-20）
  - 已完成：显示"已完成"状态

### 5. 数据更新
- **计划时间**：为所有计划中的小组添加了具体的开启时间
- **进度跟踪**：为进行中的小组添加了进度百分比
- **状态管理**：完善了状态标识和进度跟踪系统

## 技术实现

### 状态标识组件
```typescript
{/* 状态指示器 */}
<div className={`absolute -top-1 -right-1 w-3 h-3 rounded-full ${
    group.status === 'active' ? 'bg-orange-500' :
    group.status === 'completed' ? 'bg-green-500' :
    'bg-gray-400'
}`}></div>
```

### 状态详情显示
```typescript
<span className="text-gray-400">
    {group.status === 'active' && group.progress ? `${group.progress}%` :
     group.status === 'planning' && group.planningStartDate ? group.planningStartDate :
     group.status === 'completed' ? '已完成' : '计划中'}
</span>
```

### 数据接口扩展
```typescript
export interface Phase2Group {
    // ... 其他属性
    planningStartDate?: string; // 计划开启时间
    progress?: number; // 进度百分比
}
```
