# 胶片漂流画廊 (Gallery)

## 功能概述

胶片漂流画廊是一个瀑布流展示界面，用于展示第二期胶片漂流计划中的所有照片和留言图片。

## 主要功能

### 1. 瀑布流布局
- **响应式设计**: 根据屏幕宽度自动调整列数
  - 手机端 (< 640px): 1列
  - 平板端 (640px - 768px): 2列
  - 小桌面 (768px - 1024px): 3列
  - 桌面端 (1024px - 1280px): 4列
  - 大屏幕 (> 1280px): 5列

- **智能布局算法**: 自动将图片分配到最短的列，确保视觉平衡

### 2. 照片展示
- **双类型支持**: 
  - 主照片 (蓝色标签)
  - 留言图片 (绿色标签)
- **悬停效果**: 鼠标悬停显示位置信息和下载按钮
- **简洁设计**: 只显示图片，信息通过悬停交互展示

### 3. 搜索和过滤
- **搜索功能**: 支持按参与者、地点、留言内容搜索
- **省份过滤**: 按省份筛选照片
- **类型过滤**: 按照片类型（主照片/留言图片）筛选
- **实时过滤**: 输入即时生效
- **瀑布流展示**: 采用瀑布流布局，自动适配不同屏幕尺寸

### 4. 照片详情
- **点击查看**: 点击照片打开详情模态框
- **详细信息**: 显示完整的拍摄信息和留言
- **下载功能**: 支持下载原图
- **标签展示**: 显示照片相关标签

### 5. 统计信息
- **总照片数**: 显示所有照片的总数
- **分类统计**: 分别显示主照片和留言图片的数量

## 技术实现

### 组件结构
```
Gallery (主页面)
├── WaterfallGallery (瀑布流组件)
│   ├── 响应式列布局
│   ├── 图片卡片
│   └── 悬停效果
└── 照片详情模态框
    ├── 大图展示
    ├── 详细信息
    └── 操作按钮
```

### 数据流
1. 从 `phase2Data.ts` 加载所有 relay 数据
2. 提取所有照片和留言图片
3. 创建统一的 `PhotoItem` 数据结构
4. 应用过滤和搜索逻辑
5. 传递给瀑布流组件进行渲染

### 性能优化
- **懒加载**: 使用 `SmartImage` 组件进行图片懒加载
- **虚拟化**: 瀑布流算法优化大量图片的渲染
- **防抖**: 搜索输入使用防抖处理
- **响应式**: 窗口大小变化时重新计算布局

## 使用方法

1. 访问 `/phase2/gallery` 路径
2. 或从第二期首页点击"浏览作品集"按钮
3. 使用顶部搜索框搜索特定内容
4. 使用过滤器按省份或类型筛选
5. 点击任意照片查看详情
6. 在详情页面可以下载照片
