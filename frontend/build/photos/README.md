## 照片要求
- 格式：JPG/JPEG
- 尺寸：建议 1200x1200 像素以上
- 文件大小：建议每张不超过 2MB
- 命名：photo1.jpg, photo2.jpg, photo3.jpg

## 使用方法
1. 将你的照片按照上述目录结构放置
2. 确保照片路径与 `frontend/src/config/projectData.ts` 中的配置一致
3. 照片会自动在网站中显示

## 注意事项
- 照片路径区分大小写
- 确保照片文件存在，否则会显示加载错误
- 建议使用有意义的照片内容，与留言内容相呼应
