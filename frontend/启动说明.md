# 胶片漂流计划 - 前端启动说明

## 项目概述
这是一个跨越地域、连接心灵的摄影接力项目。四个小组，二十四位摄影师，用胶片记录旅途中的每一个瞬间。

## 项目结构
```
frontend/
├── src/
│   ├── components/          # 组件目录
│   │   └── Navbar.tsx      # 导航栏组件
│   ├── pages/              # 页面目录
│   │   ├── Home.tsx        # 首页
│   │   ├── GroupDetail.tsx # 小组详情页
│   │   ├── RelayDetail.tsx # 接力棒详情页
│   │   └── About.tsx       # 关于页面
│   ├── config/             # 配置文件目录
│   │   └── projectData.ts  # 项目数据配置
│   ├── App.tsx             # 主应用组件
│   ├── index.tsx           # 入口文件
│   └── index.css           # 全局样式
├── photos/                 # 照片目录
├── public/                 # 静态资源
└── package.json            # 项目依赖
```

## 快速启动

### 1. 安装依赖
```bash
cd frontend
npm install
```

### 2. 启动开发服务器
```bash
npm start
```

项目将在 http://localhost:3000 启动

## 配置说明

### 照片配置
项目支持多张照片，每棒可以配置多张照片：

1. **照片目录结构**：在 `frontend/photos/` 下创建对应的目录
2. **照片命名**：photo1.jpg, photo2.jpg, photo3.jpg
3. **配置修改**：在 `src/config/projectData.ts` 中修改照片路径

### 数据配置
所有项目数据都在 `src/config/projectData.ts` 中配置：

- **小组信息**：A、B、C、D四个小组
- **接力棒信息**：每棒6位摄影师
- **照片路径**：支持多张照片
- **留言内容**：每棒的摄影师留言
- **地理位置**：精确的经纬度坐标
- **标签系统**：每棒的主题标签

### 地图功能
项目预留了地图组件接口，可以集成：
- Google Maps API
- 高德地图 API
- 百度地图 API

## 自定义配置

### 修改照片路径
在 `src/config/projectData.ts` 中修改 `PHOTO_PATHS` 配置：

```typescript
const PHOTO_PATHS = {
    A: {
        1: [
            '/your/custom/path/photo1.jpg',
            '/your/custom/path/photo2.jpg',
            '/your/custom/path/photo3.jpg'
        ],
        // ... 其他配置
    }
};
```

### 修改留言内容
在 `MESSAGES` 配置中修改留言：

```typescript
const MESSAGES = {
    A: {
        1: '你的自定义留言内容',
        // ... 其他配置
    }
};
```

### 修改地理位置
在 `COORDINATES` 配置中修改坐标：

```typescript
const COORDINATES = {
    A: {
        1: { lat: 你的纬度, lng: 你的经度 },
        // ... 其他配置
    }
};
```

## 技术栈

- **前端框架**：React 18 + TypeScript
- **样式系统**：Tailwind CSS
- **动画库**：Framer Motion
- **图标库**：Lucide React
- **路由系统**：React Router v6

## 注意事项

1. **照片格式**：建议使用 JPG 格式，确保兼容性
2. **照片大小**：建议每张不超过 2MB，优化加载速度
3. **照片尺寸**：建议 1200x1200 像素以上，保证显示质量
4. **路径配置**：确保照片路径与配置文件一致
5. **浏览器兼容**：支持现代浏览器，建议使用 Chrome、Firefox、Safari

## 常见问题

### Q: 照片无法显示？
A: 检查照片路径是否正确，确保文件存在于指定目录

### Q: 如何添加新的小组？
A: 在 `projectData.ts` 中添加新的小组配置

### Q: 如何修改页面样式？
A: 修改对应的 CSS 文件或 Tailwind 类名

### Q: 如何集成地图？
A: 替换地图占位符，集成相应的地图 API
